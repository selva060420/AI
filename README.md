# AI

## Student Report Card Generator

A simple Python application that generates formatted report cards for students.

### Features
- Input student ID and name
- Enter marks for 5 subjects (Math, Science, English, History, Art)
- Stores marks in a dictionary
- Calculates average and assigns grade (A-F)
- Prints formatted report card

### Usage
```bash
python student_report_card.py
```

### Grading Scale
- A: 90-100
- B: 80-89
- C: 70-79
- D: 60-69
- F: Below 60

## Personal Expense Tracker

A simple Python application to track daily expenses.

### Features
- Add daily expenses with category and amount
- Store expenses in a list of dictionaries
- Calculate total spent and highest expense
- View expenses grouped by category

### Usage
```bash
python expense_tracker.py
```
